Pengertian AP Outdoor

Access Point Outdoor adalah perangkat jaringan yang digunakan untuk menyebarkan sinyal WiFi di luar ruangan seperti halaman sekolah, lapangan, taman, area parkir, atau antar gedung. Alat ini dibuat tahan terhadap panas, hujan, dan angin.

Mode AP (Access Point)

Mode AP adalah mode di mana perangkat berfungsi untuk menyebarkan jaringan internet dari kabel LAN ke perangkat lain melalui WiFi.

Gambar Alat

Langkah Setting AP Outdoor Mode AP

  1. Hubungkan AP Outdoor ke laptop menggunakan kabel LAN
  2. Buka browser dan masuk ke IP Address AP (contoh: 192.168.1.1)
  3. Login menggunakan username dan password admin
  4. Pilih mode kerja: Access Point (AP Mode)
  5. Atur SSID (nama WiFi)
  6. Atur keamanan WiFi dan password
  7. Simpan pengaturan lalu restart perangkat
  8. Pasang AP Outdoor di luar ruangan
